# JavaScript Number Operations Assignment

A JavaScript application that processes numbers to perform operations like computing digit sums, testing for Armstrong numbers, checking primality, and listing factors.

## Objective

Demonstrate the use of control structures (loops, conditionals), arrays, and functions in JavaScript by analyzing a set of input numbers.

## Features

- **Sum of First N Numbers**: Calculates the arithmetic sum from `1` to `N`.
- **Multiplication Table**: Generates a 1-to-10 table for a given number.
- **Sum of Digits**: Breaks down a number to sum its individual digits.
- **Armstrong Number Check**: Verifies if the sum of digits raised to the power of 3 equals the original number.
- **Prime Number Check**: Determines if a number is prime using trial division.
- **Factor Finder**: Lists all positive integers that divide the number evenly.
